# EcoMix / Eco News — versão pronta para GitHub + Vercel

## Como publicar no GitHub

1. Extraia esta pasta no computador.
2. Abra o repositório `luid1/ecomix`.
3. Clique em **Add file → Upload files**.
4. Selecione **o conteúdo desta pasta**, não o arquivo ZIP.
5. Mantenha a estrutura das pastas `api/` e `assets/`.
6. Faça o commit.

### Estrutura principal

- `index.html` — site principal EcoMix
- `ecomix-news.html` — portal Eco News
- `ecomix-news-artigo.html` — página das matérias
- `styles.css` — estilos
- `script.js` — scripts do site
- `api/news.js` — API de notícias
- `api/image.js` — proxy de imagens
- `assets/` — imagens e logos

A versão não inclui versões antigas ou a pasta `v12`, para evitar enviar arquivos duplicados ao GitHub.

## Vercel

O projeto pode ser importado diretamente do repositório. Não é necessário enviar o ZIP para o GitHub.
