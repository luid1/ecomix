# EcoMix Gestão Ambiental — Vercel

Projeto preparado para Vercel. O Eco News usa uma Vercel Function em `api/news.js` (Node.js) em vez de PHP.

## Publicação
1. Importe este projeto na Vercel.
2. Não precisa configurar build command para este site estático.
3. Deploy.
4. Depois adicione `ecomixgestaoambiental.com.br` em Settings > Domains.

O e-mail continua na Umbler: não altere os registros MX/TXT usados pelo e-mail. No DNS da Umbler, apenas aponte o domínio do site conforme os registros mostrados pela Vercel.
